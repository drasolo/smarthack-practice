## Cum s-a format folderul

Sursele sunt prezentarea PPC, site-ul și regulamentul SmartHack, documentul „SmartHack 2026:
pregătire” (3 noiembrie), notițele „PPC Briefing” (31 octombrie), backtest-ul PZU și o conversație
despre firmă și teme. Din ele au rămas doar părțile încă valabile. De exemplu, cheia API pentru
LLM-ul din produs a fost scoasă, pentru că am decis să nu folosim chei API.

De acum înainte, acest folder este versiunea curentă. Documentele vechi din Claude nu se mai
actualizează.
